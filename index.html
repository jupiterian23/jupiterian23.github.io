Things I built and broke

EC2 web server and cloud infrastructure

Built
An EC2 Linux instance running Nginx in a public subnet, with S3 buckets and IAM users managed entirely through the AWS CLI.
Broke
The site was unreachable from the internet while the instance showed as running. SSH worked and curl localhost returned the page, which ruled out the web server and pointed at the network layer.
Found
No inbound rule for port 80 in the Security Group. Separately, an AccessDenied on S3 turned out to be an IAM policy granting object access but not bucket-level listing — two different ARN patterns for what felt like one permission.

EC2 · Nginx · IAM · VPC · Security Groups · S3 · AWS CLI · Linux
